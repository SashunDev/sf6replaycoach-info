SF6ReplayCoachは、Street Fighter 6の対戦セッションをPC上で整理し、試合ごとの完成動画の再生・保存、対戦相手キャラクターや勝敗の確認・修正を支援する個人用Windowsアプリです。

YouTube連携は任意・既定OFF
プライバシーポリシーを見るYouTube連携について

主な機能

試合動画の整理

録画・取り込んだセッションから、試合ごとの完成動画を扱い、再生やファイル保存を行います。

戦績の確認

対戦相手キャラクターや勝敗を確認できます。必要に応じて、利用者が記録を修正できます。

任意のYouTube投稿

投稿する動画を利用者が選び、確認画面で承認した場合だけ、専用YouTubeチャンネルへ限定公開で投稿します。

ローカルデータの保護

録画原本や完成動画、記録をPCで管理します。YouTubeへの投稿を理由に録画原本を自動削除することはありません。

YouTube API連携の仕組み

SF6ReplayCoachはYouTube API Servicesを使用します。接続時にはGoogleのOAuth同意画面が開き、投稿先チャンネルを確認します。

  • 使用する権限は、YouTubeの読み取りと動画アップロードです。
  • 自動投稿は行いません。利用者が完成動画を選び、最終確認してから投稿します。
  • 投稿時に公開範囲を「限定公開（unlisted）」に指定し、APIを使って状態を確認します。
  • 接続情報はPCのWindows資格情報マネージャーに保存します。投稿履歴はPC内に保存します。
  • YouTubeとの接続を設定しなくても、基本的なローカル機能を利用できます。
限定公開は完全な非公開ではありません。 動画のURLを知っている人は視聴できます。公開前に、動画の権利・音声・個人情報を確認してください。

YouTube連携に関する詳しいデータの取り扱いはプライバシーポリシーをご覧ください。

本アプリは個人利用を目的として開発・運用されています。このWebサイトはOAuth連携の説明とプライバシーポリシーを公開するためのものです。非公開のソースコード、Google認証情報、実際の試合動画を掲載するものではありません。
