概要

SF6ReplayCoachは個人向けWindowsアプリです。YouTube連携は任意であり、利用者が明示的に承認した完成動画のみをYouTubeへ送信します。Google OAuthの認証情報はWindows資格情報マネージャー、投稿履歴はPC内のローカルファイルで管理します。

1. 適用範囲

本ポリシーは、SF6ReplayCoachのGoogle OAuthおよびYouTube API Servicesを使う機能における情報の取得、使用、保存、共有、削除について説明します。YouTube連携を行わない基本的な動画管理機能は、Googleアカウント接続なしで利用できます。

2. 要求するGoogleの権限と利用目的

Google OAuthを通じて次の権限を要求します。

  • youtube.readonly：接続したYouTubeチャンネルを確認し、アップロードした動画の公開範囲や処理状態を照合するため。
  • youtube.upload：利用者が指定・承認した動画を、利用者のYouTubeチャンネルに投稿するため。

具体的には、チャンネルID・表示名、投稿した動画のID・チャンネルID・公開範囲・アップロード状態・処理状態など、機能に必要な情報を取得します。これらの情報を広告のターゲティング、データ販売、信用評価、監視目的には使用しません。

3. YouTubeに送信するデータ

利用者が投稿確認画面で対象を確認して確定したときだけ、選択した完成MP4動画とそのタイトル等のメタデータをYouTube Data APIを通じてGoogleへ送信します。タイトルには、セッション日時、使用キャラクター、対戦キャラクター、勝敗、セッション内の試合番号が含まれます。投稿時の公開範囲は「限定公開（unlisted）」を指定します。

限定公開はURLを知る人が視聴できる設定です。YouTube上のプライバシー設定や削除は利用者がYouTube Studioで管理します。SF6ReplayCoachは投稿済み動画を自動削除したり、公開範囲を自動変更したりしません。

4. PC内での保存

  • Windows資格情報マネージャー：Google OAuthクライアントID・クライアントシークレット、リフレッシュトークン、投稿先チャンネル情報、必要時の再開用アップロードセッション情報を、利用者のWindowsアカウントの保護領域に保存します。
  • ローカル投稿履歴：投稿ジョブのID、日時、試合・動画に関する識別情報、タイトル、投稿先チャンネルID、YouTube動画ID、アップロード・処理状態などをアプリデータ内のJSONファイルに保存します。
  • 録画・完成動画：PCで管理し、明示的に選んだ動画以外はYouTubeへ送信しません。投稿を理由として元動画や完成動画を自動で削除することはありません。

投稿履歴は明示的な操作または利用者によるローカルデータの管理まで残ります。一定日数での自動削除は行っていません。認証情報を通常のログや公開Webページ、公開GitHubリポジトリへ書き込まない設計です。

5. データの共有先と利用制限

投稿を確定すると、動画と必要なメタデータはGoogle（YouTube）に送信され、Googleの利用規約とプライバシーポリシーに従って取り扱われます。Google APIから取得した情報を、広告会社、データブローカー等に販売・提供することはありません。YouTube API Servicesに関するユーザーデータの利用は、アプリが提供する上記機能のために限定します。

6. 連携の解除とデータの削除

  • SF6ReplayCoach内の「この PC の接続情報を削除」で、このPCに保存されたYouTube接続情報を削除できます。
  • Googleアカウントの接続管理で、Google側の許可を取り消せます。
  • 接続解除だけでは、PC内の投稿履歴やYouTubeに投稿済みの動画は削除されません。動画の削除はYouTube Studioで利用者が行います。
  • ローカル投稿履歴の削除は未完了ジョブや重複投稿防止の情報に影響するため、必要な場合は先にサポート窓口へご相談ください。

7. YouTube・Googleの規約

SF6ReplayCoachはYouTube API Servicesを利用しています。利用者は、YouTubeの機能を利用する際にYouTube利用規約を遵守する必要があります。また、GoogleプライバシーポリシーおよびYouTube API Servicesデベロッパーポリシーもご参照ください。

8. この説明サイトについて

このWebサイトは公開アプリ情報の掲載を目的とする静的サイトです。サイト自身に、独自のトラッキングスクリプト、アクセス解析タグ、アカウント作成機能、入力フォームは設けていません。ホスティング事業者（GitHub Pages等）が配信に伴って収集する情報は、その事業者のポリシーに従います。

9. 更新と問い合わせ

機能やデータの取り扱いを変更する場合、本ポリシーを更新します。お問い合わせ・プライバシーに関する依頼は公開用リポジトリのIssues、またはOAuth同意画面に表示されるユーザーサポートメールへご連絡ください。公開Issuesには認証情報や個人情報を記載しないでください。
